# Lab 01 — Scripts

Provisioning and failure-injection scripts will live here.

Scripts must:
- Be scoped to the disposable lab VM.
- Be safe to rerun where possible.
- Clearly separate environment setup from fault injection.
- Avoid secrets and destructive host-level operations.
- Print a concise completion summary.

The first failure-injection script will be added after validating the selected Fedora VMware box and successful clean provisioning.
