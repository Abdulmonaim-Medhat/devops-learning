# Month 01 — Linux, Networking & Infrastructure Fundamentals

**Duration:** 4 weeks  
**Time budget:** 5–7 hours/week  
**AWS budget:** $0 — use local VMware labs.

## Objectives

Strengthen the fundamentals needed to operate and troubleshoot production Linux and cloud infrastructure.

## Weekly plan

| Week | Focus | Practical outcome |
|---|---|---|
| 01 | Linux internals, processes, systemd, filesystems and permissions | Diagnose Linux service and resource issues |
| 02 | TCP/IP, DNS, routing, firewalls and packet analysis | Troubleshoot connectivity and name-resolution failures |
| 03 | HTTP, TLS, Nginx, application and database connectivity | Trace requests through a multi-tier application |
| 04 | Infrastructure architecture, dependencies and monitoring | Document and troubleshoot the existing lab architecture |

## Lab environment

- Host: Windows + VMware Workstation.
- Existing management VM: Fedora Server / Fedora Workstation.
- Additional Linux workers can be powered on only when required.
- Disposable scenario VMs will be provisioned with Vagrant where practical.

## Completion criteria

- Explain the relevant concepts in your own words.
- Diagnose scenarios using evidence before changing configuration.
- Reproduce and resolve failures independently.
- Document root cause, fix, verification and prevention.
- Explain the troubleshooting process clearly in English.
