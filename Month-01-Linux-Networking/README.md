# Linux, Networking & Infrastructure Fundamentals

This section contains practical exercises and reference material for administering, operating, and troubleshooting Linux systems and infrastructure services.

## Topics covered

- Linux processes, signals, and systemd
- Filesystems, storage, ownership, and permissions
- CPU, memory, and process troubleshooting
- TCP/IP, DNS, routing, and firewall fundamentals
- Packet analysis and connectivity troubleshooting
- HTTP, TLS, reverse proxies, and application connectivity
- Infrastructure architecture, service dependencies, and monitoring

## Lab environment

Labs may use local virtual machines, containers, or cloud resources depending on the exercise. Keep environments reproducible and resource-efficient.

## Practical objectives

- Diagnose issues using evidence before changing configuration.
- Reproduce and resolve service and connectivity failures.
- Understand dependencies between infrastructure components.
- Document root causes, remediation, verification, and prevention.
- Use standard Linux and networking diagnostic tools effectively.
